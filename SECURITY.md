# Security Policy

## Supported Versions

Below is the list of supported versions for this project. Versions marked with ✅ are actively maintained and receive security updates. Versions marked with ❌ are no longer supported.

| Version | Supported          |
| ------- | ------------------ |
| 5.1.x   | ✅ (Latest stable release) |
| 5.0.x   | ❌ (Deprecated)     |
| 4.0.x   | ✅ (Maintained for long-term academic compatibility) |
| < 4.0   | ❌ (Outdated and unsupported) |

## Reporting a Vulnerability

If you discover a security vulnerability in this project (for example, issues related to cryptographic implementation, code injection, or unauthorized data access), please report it responsibly.

### How to Report

- **Preferred Method**: Email the project maintainer directly at `security.vk.projects@protonmail.com`.
- **Alternative Method**: Open a confidential issue on the GitHub repository and mark it as "Security".
- Please provide:
  - A clear description of the vulnerability
  - Steps to reproduce the issue
  - Potential impact and affected components
  - Suggested remediation (if applicable)

### Response Expectations

- Acknowledgement of the report within **48 hours**
- A preliminary investigation and response within **5 business days**
- Patches or mitigation instructions within **2–4 weeks**, depending on severity
- You will be notified when the fix is released or if the issue is not deemed a security risk

### Responsible Disclosure

Please do not publicly disclose vulnerabilities before a patch has been released. If you believe there is an immediate and severe risk, indicate that in your report so it can be prioritized accordingly.

Thank you for helping keep the community safe.
